# Влияние частотного состава остаточной функции на точность гибридной нейросетевой аппроксимации

Рабочая аннотированная редакция по материалам экспериментов 38–46. Не рецензирована.

## Постановка задачи

Для статической зависимости f(x) и априорной модели f₀(x) остаток r(x)=f(x)−f₀(x). Гибридная аппроксимация f̂(x)=f₀(x)+g(x) имеет ошибку r(x)−g(x).

В синтетическом исследовании гармоники rₖ(x)=0,1√2 sin(2πkx) на [0,1] имеют одинаковый RMS 0,1. Рассматриваются k=1, 2, 4, 8. RMS второй производной равен 0,1(2πk)². Это не универсальный показатель сложности функции.

Приведены средние RMSE из сохранённой сводки экспериментов. Для NN 32 отношение ошибок при k=8 и k=1 составляет около 14,7. Сплайн в данном примере показал меньшую ошибку. Результат не означает невозможность аппроксимации высоких частот нейросетями и согласуется с известной литературой о спектральном смещении.

## Ограничения

Одномерная синтетическая статическая регрессия; конечный бюджет обучения; ограниченные архитектуры; обусловленность выводов выбранным семейством функций. Частота и RMS второй производной здесь не разделены. Нельзя переносить выводы на устойчивость динамических систем. Для установления оригинального вклада нужен дополнительный обзор литературы.
