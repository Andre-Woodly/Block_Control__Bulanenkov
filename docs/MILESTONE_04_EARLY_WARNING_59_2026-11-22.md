# Контрольная точка № 04 — предварительная диагностика недостоверности NN-прогноза

**Дата:** 22 ноября 2026 г.  
**Эксперимент:** № 59  
**Исследуемая архитектура:** неполная математическая модель M0 + отключаемая нейросетевая поправка.  
**Область:** синтетическая пассивная динамика двух тепловых состояний, только прогнозирование, без управляющих воздействий.

## Вопрос

Можно ли по истории *уже доступных* измерений (моменты 0, 5, 10, 15, 20 мин) заранее распознать изменение условий, потенциально ухудшающее прогноз NN-корректора на будущие моменты 25, 30, 40, 60 мин?

Различаются две задачи:

- **Обнаружение изменения распределения входных наблюдений** — произошло ли что-то нетипичное относительно номинала.
- **Предсказание ошибки конкретного будущего прогноза** — окажется ли этот прогноз за ранее откалиброванным 90%-м интервалом.

Это не одно и то же. Принятие сигнала о смене условий **не** означает гарантии прогнозной ошибки.

## Методика

Базовый прогноз — **среднее пяти независимо инициализированных гибридных NN** из эксперимента № 58, обученных на широком диапазоне параметров; математический компонент M0 фиксирован. Среднее пяти NN здесь отличается от метрики эксперимента № 58, где RMSE сначала рассчитывалась для каждой NN и затем усреднялась.

Пять наблюдаемых предикторов предупреждения:

1. Остаток аппроксимации наблюдаемой истории двумя состояниями номинальной математической модели (history_fit).
2. Несоответствие последнего известного измерения прогнозу из первых четырёх отсчётов (last_innovation).
3. Расстояние Махаланобиса измеренной истории от номинальных обучающих наблюдений (mahalanobis).
4. Величина прогнозной NN-поправки относительно M0 (correction_size).
5. Разброс прогнозов по пяти инициализациям NN (nn_disagreement).

Общий индикатор **combined** — максимум пяти нормированных показателей. Пороги для каждого показателя отдельно устанавливались по **400 независимым номинальным траекториям** на уровне 90-го процентиля. Для прогнозного 90%-го интервала применялись **другие 400 траекторий**, что разделяет калибровку прогноза и калибровку предупреждения. Калибровка на номинале не означает гарантии при изменении распределения.

Объём: 1200 обучающих номинальных траекторий для распределения индикаторов, 1200 для обучения широкого NN-корректора, тест **1200 независимых траекторий на каждый из пяти сценариев**, 5 NN, 500 шагов Adam, random seeds 4, 17, 29, 41, 53. Все признаки индикаторов рассчитываются **без использования будущих измерений**; последние используются только для итоговой оценки качества предупреждений.

Номинальный полуширина одновременно покрывающего 4 горизонта интервала: **0,75890 °C**. «Будущий промах» определяется как превышение этой величины максимальной абсолютной ошибкой на хотя бы одном из четырёх горизонтов.

## Результаты общего предупреждающего индикатора

| Тестовые условия | Доля предупреждений | Доля будущих промахов | Доля промахов, замеченных предупреждением | ROC-AUC для прогноза будущего промаха |
|---|---:|---:|---:|---:|
| Номинальные | **9,0%** | **8,33%** | **27,0%** | **0,653** |
| Разброс параметров внутри обучающего диапазона | **13,75%** | **15,17%** | **20,9%** | **0,557** |
| Одна новая комбинация внутри диапазона | **21,08%** | **4,17%** | **42,0%** | **0,657** |
| Параметры за пределами диапазона | **66,08%** | **61,75%** | **64,9%** | **0,494** |
| Повышенный шум измерений | **86,42%** | **85,50%** | **87,6%** | **0,609** |

**95%-е бутстреп-интервалы ROC-AUC общего индикатора:** номинал **[0,585; 0,711]**; параметры за обучающим диапазоном **[0,461; 0,532]**; повышенный шум **[0,565; 0,652]**. Бутстреп по тестовым траекториям при фиксированных обученных сетях; неопределённость повторного обучения не включена.

**Оценки неопределённости доли предупреждений (Wilson 95%):** номинал **[7,51%; 10,75%]**; параметры вне диапазона **[63,36%; 68,71%]**; повышенный шум **[84,36%; 88,24%]**. Это эмпирические интервалы при данной синтетической выборке.

## Основные наблюдения

### 1. Сильные изменения распределения можно заметить заранее

Частота предупреждений выросла с **9% в номинале** до **66% при выходе параметров за диапазон** и до **86% при повышенном шуме**.

Такие предупреждения рассчитываются в момент последнего доступного измерения, до наблюдения будущих температур. Это означает, что история несёт диагностическую информацию об изменении режима.

### 2. Это не надёжный предсказатель каждого промаха

При выходе параметров за диапазон общий индикатор пропустил **260 из 741** будущего промаха. ROC-AUC в этом сценарии **0,494**, то есть по ранжированию риска будущей ошибки он не лучше случайного уровня. Более того, доля промахов *при предупреждении* была **60,7%**, а *без предупреждения* — **63,9%**.

Показатель способен заметить, что условия отличаются от номинальных, но не даёт корректной индивидуальной оценки будущей ошибки.

### 3. У разных признаков разные сильные и слабые стороны

- Номинальный физический остаток по истории срабатывает в **71,3%** случаев при параметрах вне диапазона и в **89,8%** случаев повышенного шума, при **10,5%** на номинале.
- Размер NN-поправки обнаруживает параметры вне диапазона только в **6,9%** случаев, несмотря на большой рост реальных ошибок.
- Разброс NN между seed при выходе параметров за диапазон срабатывает в **26,5%**, а ROC-AUC по будущим промахам там **0,288**. Сам по себе разброс сети — ненадёжный универсальный индикатор.
- При новой комбинации внутри обучающего диапазона общий индикатор предупреждал в **21,1%** случаев, хотя доля промахов была только **4,2%**. Необычность входных наблюдений и практическая ошибка прогноза не тождественны.

## Что закрыли и что не закрыли

**Закрыто для синтетического примера:** реализованы независимые индикаторы до будущего наблюдения; проверена их реакция на распределительные сдвиги; проведено честное разделение калибровочных данных; измерено качество предупреждений и доля пропусков.

**Не доказано:** универсальный детектор недостоверности; автоматическая гарантия достоверного прогноза при предупреждении/без него; перенос на физические приводы; устойчивость замкнутого управления; научная новизна относительно существующих методов мониторинга.

## Воспроизведение

- `experiment.py` — воспроизводимый код № 59; использует соседний исходный код № 58 (`../passive_thermal_58/experiment.py`).
- `metrics.csv` — таблица по пяти индикаторам и объединению на пяти сценариях.
- `calibration.csv` — пороги предупреждений и нормирующие значения.
- `individual_outcomes.csv` — результаты всех 6000 проверочных траекторий для общего индикатора.
- `run_metadata.json` — версия библиотек, seed, хэши исходников, уровни порогов.
- `run.log` — неизменённый журнал выполнения.
- `alarms.png`, `auc.png` — графики.

Команда: `python experiments/passive_thermal_59/experiment.py --outputs-dir results/passive_thermal_59` (после установки Python-библиотек numpy, pandas, scipy, torch, matplotlib).
