# Контрольная точка №08 — динамические критерии и устойчивость по Ляпунову

**Дата:** 22.11.2026. **Связь с прежней работой:** эксперимент №67, модели М0/М0+пересчёт/М0+пересчёт+NN и независимый полиномиальный корректор. **Проверенная область:** только учебная двухсостоянийная система регулирования температуры, без реального привода.

## 1. Цель

Проверить не только RMSE замкнутого контура, но и IAE, ITAE, перерегулирование, время нарастания, установившуюся ошибку, изменчивость воздействия, насыщение и функцию Ляпунова. Уточнить, что именно пересчитывается: **оценки коэффициентов математической модели**, а не физическая конструкция объекта; веса NN после offline-обучения фиксированы.

## 2. Протокол

- Исходный код №67 повторно использован без изменения физической постановки: два тепловых состояния (измеряемое и скрытое), дискретный шаг Δt=0,2 условной единицы времени; модель с кубической нелинейностью. Вариации параметров задаются только между сценариями. М0 содержит два пересчитываемых эффективных коэффициента, оценки получают из последних 18 причинно доступных наблюдений.
- Новый тест на ступенчатую цель +0,35 условной единицы от начального состояния после одинакового предварительного участка. Длина 220 шагов (44 условные единицы времени); 140 тестовых траекторий в каждом сценарии, 2 обучающих набора × 2 независимые инициализации = 4 повторения. Возмущения и шум одинаковы для сравниваемых методов.
- Сравниваются фиксированная М0, М0 с пересчётом, М0 с пересчётом и NN, М0 с пересчётом и простым полиномиальным остатком. Дополнительные базисы (М0+NN без пересчёта и упрощённый «оракул» с истинными коэффициентами) сохранены в CSV.
- Отдельная проверка нулевой цели: численно отслеживается V на 120 начальных состояниях × 140 шагов для каждого сценария и вариантов: без шума; шум датчика; шум + внешнее случайное возмущение.

## 4. Аналитическая проверка по Ляпунову

Учебная **непрерывная** физическая модель:

`A˙=−p_a A + p_c(W−A)−p_b A³+p_g u+d;   W˙=p_w(A−W)`.

Введём общую для всех пяти тестовых наборов параметров функцию `V(A,W)=½ A² + (κ/2)W²`, где **κ=2**, так что V положительно определена.

В отсутствие возмущений при идеальном линейном законе `u=−k A`, k≥0, производная:

`V˙=−(p_a+p_c+p_g k)A² + (p_c+κ p_w)A W −κ p_w W² − p_b A⁴ = −zᵀQz−p_b A⁴`,

где `z=[A,W]ᵀ`, `Q=[[p_a+p_c+p_g k,−(p_c+κ p_w)/2],[−(p_c+κ p_w)/2,κ p_w]]`.

Если Q положительно определена, то для `λ=λmin(P⁻¹ᐟ² Q P⁻¹ᐟ²)>0`, `P=diag(1,κ)`, имеем `V˙≤−2λV`, то есть **глобальную экспоненциальную устойчивость** нулевого состояния идеальной непрерывной модели. Одинаковая матрица P означает *общую* функцию Ляпунова для проверенных вариантов физических коэффициентов.

| Параметры объекта | Минимальная подтверждённая скорость 2λ при k=0 | При k=0,6 |
|---|---:|---:|
| Номинал | 0.04861 | 0.07775 |
| Изменение 2 параметров | 0.05775 | 0.07717 |
| Рост нелинейности | 0.04861 | 0.07775 |
| Совместное изменение | 0.02560 | 0.04137 |
| Повышенный шум | 0.04861 | 0.07775 |

**Математическая область вывода:** только непрерывная двухсостоянийная модель при `d=0`, точном состоянии A, идеальном законе `u=−kA` и параметрах из выписанных сценариев (также из их выпуклой оболочки, поскольку Q зависит от параметров аффинно). Проверка сетки из 100 000 случайных состояний на каждый случай дала ноль нарушений, но доказательством здесь служит **положительная определённость Q**, а не перебор точек.

**Ограничение:** этот вывод **не доказывает** устойчивость фактически смоделированного регулятора, использующего сетку дискретных воздействий, насыщения, оценку коэффициентов, NN, истории наблюдений и шум. Для такого контура нужны дополнительные условия на закон отображения и, возможно, расширенное состояние.

## 5. Численная проверка V в фактическом учебном замкнутом контуре

При постоянной нулевой цели функция V убывала на всех проверенных шагах **тихого сценария без шума и внешних возмущений** (это эмпирика, не теорема). При шуме и возмущениях рост энергии отмечался и у математической, и у гибридной схемы.

| Сценарий | Метод | Доля шагов с ΔV>0: тихо | Доля при шуме+возмущении | Доля траекторий с хотя бы одним ростом V |
|---|---|---:|---:|---:|
| Номинал | М0 | 0.000 | 0.148 | 0.992 |
| Номинал | М0 + пересчёт | 0.000 | 0.145 | 0.992 |
| Номинал | М0 + пересчёт + NN | 0.000 | 0.122 | 0.908 |
| Совместное изменение | М0 | 0.000 | 0.054 | 0.450 |
| Совместное изменение | М0 + пересчёт | 0.000 | 0.055 | 0.425 |
| Совместное изменение | М0 + пересчёт + NN | 0.000 | 0.049 | 0.358 |
| Повышенный шум | М0 | 0.000 | 0.363 | 1.000 |
| Повышенный шум | М0 + пересчёт | 0.000 | 0.324 | 1.000 |
| Повышенный шум | М0 + пересчёт + NN | 0.000 | 0.277 | 1.000 |

**Почему V может расти:** член `(p_g u+d)A` может быть положительным; присутствуют дискретизация, шумные измерения и нелинейное правило выбора действия. Убывание V на всех дискретных шагах **не требуется** для устойчивости в смысле ограниченной реакции на ограниченные возмущения. Но ISS-свойство фактической гибридной системы этим экспериментом не доказано.

## 6. Итог для нашей гипотезы

1. Математический пересчёт характеристик означает обновление коэффициентов М0 по истории измерений. Физический двухсостоянийный объект остаётся тем же по структуре; параметры моделируемого объекта меняются только как сценарий.
2. При совместном изменении параметров пересчёт М0 снижал шаговую RMSE с 0,02920 до 0,02640, но добавление NN повышало её до 0,02690 (ухудшение относительно пересчёта).
3. При повышенном шуме RMSE: М0 0,06351; пересчёт 0,0553; пересчёт+NN 0,0491; пересчёт+полином 0,0485. **NN помогает относительно пересчёта, но не превосходит простой полином**.
4. Снижение ошибки модели, успешное слежение и доказанная устойчивость — **три различных результата**. Аналитическое доказательство касается идеализированной непрерывной схемы; реальный NN-контур нуждается в отдельном формальном обосновании.

## 7. Ограничения и критерии дальнейшей проверки

- Виртуальные учебные единицы и искусственная тепловая система, не электромеханический/гидравлический привод.
- В новом шаговом сравнении только 2 независимых обучающих набора × 2 инициализации; статистическая неопределённость **не закрыта**. Попытка более масштабного прогона не завершена и не включена в результаты.
- Анализ по Ляпунову для физического объекта не является теоремой об устойчивости полного алгоритма (параметрический наблюдатель, NN, историческая память, дискретные ограничения).
- Время регулирования на строгой ±5%-й полосе в шумной среде требует более корректного вероятностного определения.
- Нет независимой физической валидации и доказательства изоморфизма конкретных моделей.

**Статус:** аналитическая проверка идеализированной модели завершена; проверка полной гибридной системы и её устойчивости остаётся **открытой**.
