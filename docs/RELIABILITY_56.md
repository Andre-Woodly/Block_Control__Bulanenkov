# Этап 56 — проверка достоверности прогнозов пассивной динамики
Дата: 2026-11-22. Статус: выполнен учебный численный эксперимент; выводы ограничены постановкой и бюджетом обучения.

## Исправление методики экспериментов 51–55
1. В предыдущих сравнениях при нелинейном законе использовалась только **заведомо неполная линейная** аналитическая модель. Следовательно, большой выигрыш гибридной NN над ней не доказывает преимущество над корректной математической моделью.
2. Интервалы прежде калибровались по скрытым чистым температурам симулятора. В этапе 56 они калибруются по **шумным будущим измерениям** на отдельной калибровочной выборке — это ближе к наблюдаемой задаче.
3. Это прямой прогноз шести горизонтов от одного начального измерения, а не рекурсивная симуляция/идентификация двух скрытых состояний и не замкнутое управление.

## Постановка
Синтетическая пассивная модель избытка температуры D=T−20 °C:
dD/dt=−aD−bD², a=0,02 1/мин; b=0,0008 (°C·мин)⁻¹.
При базовом прогнозе математическая составляющая гибридной модели ошибочно полагает b=0.
Истинное решение D(t)=D0 exp(−at)/[1+(b/a)D0(1−exp(−at))].
Обучающих независимых траекторий 120, калибровочных 300, проверочных 1200; 6 горизонтов 10–60 мин, шум измерений σ=0,1 °C, 5 инициализаций MLP (2–16–1), Adam 1000 шагов. Для проверки меняются только тестовые условия: σ=0,5 °C или a=0,03 при сохранении исходной модели.

Прогноз сравнивается с **шумным будущим наблюдением** (не с чистой температурой). 90%-й симультанный интервал строится по максимуму абсолютных ошибок на 6 горизонтах одной траектории; q — split-conformal квантиль на калибровке. Покрытие указано для **траекторий целиком**.

Средняя разность RMSE (полная NN минус гибридная) при совпадении условий: +0,00188 °C; 95%-й парный бутстреп-интервал по 1200 тестовым траекториям **[−0,00051; +0,00433] °C** (5 инициализаций NN фиксированы). Нельзя утверждать статистически убедительное преимущество гибридной сети: интервал содержит ноль. Интервал не учитывает неопределённость из-за другого набора обучающих траекторий.

## Выводы
- В этом искусственном примере корректное аналитическое описание точнее обеих NN при известных характеристиках.
- Неполная линейная априорная модель может быть существенно улучшена обучаемой составляющей, но это не универсальный выигрыш относительно верной математической модели.
- При смене характеристик или уровня измерительного шума прежняя 90%-я калибровка может стать недостоверной.
- По этим данным нельзя делать выводы об устойчивости регулятора, изменении реального привода или новизне изоморфного управления.

## Следующий предмет исследования
Пассивная двухсостоянийная динамика с ненаблюдаемым внутренним состоянием. Исследовать, что даёт история измерений по сравнению с единственным отсчётом, а не заявлять полученные ошибки прогноза свойствами замкнутой системы.
