# Контрольная точка № 12 — эксперимент 72: длина окна NN-корректора
Дата: 2026-11-22. Область: синтетическая двухсостоянийная тепловая система в замкнутом контуре. **Не** реальный привод.

## Архитектура и фиксируемые условия
Выбранная архитектура: **М0 + онлайн-пересчёт коэффициентов по последним 18 переходам + отключаемая NN-поправка**.
Веса NN обучены только офлайн; при моделировании меняются лишь наблюдения и оценки коэффициентов.
В эксперименте у NN история из L∈{1,2,5,10,18} наблюдений температуры и L предшествующих действий, а также текущее действие-кандидат и оценки двух коэффициентов М0. **Для всех L пересчёт М0 остаётся одинаковым: 18 переходов.**
Одинаковая NN 39–24–24–1, tanh, 270 шагов Adam с одинаковой конфигурацией; при L<18 старые поля зануляются. Это равное число параметров и итераций, но не одинаковая оптимальная информативность признаков.
Прогноз на один шаг: ŷ=ŷ_M0(ŷ по текущему измерению, u, оценкам a и g) + Δŷ_NN(история, u, оценки). Сравнение с M0 без NN и Ridge-корректором по 18 отсчётам.
В замкнутом учебном контуре конечное действие выбиралось из 9 значений по одинаковому критерию для всех методов. Ненулевое постоянное задание r=0,45; отдельно переменная последовательность заданий.
Протокол: 150 тренировочных траекторий на независимую обучающую группу; 100 тестовых траекторий на вариант; 3 независимые обучающие группы; 2 инициализации NN. Прямое сравнение на общих тестовых случайных реализациях в пределах сценария.

## Статистическая проверка (условная)
- Номинал: перетракторная RMSE NN L2 минус NN L18 = -0.00066; условный 95% иерархический бутстреп [-0.00078;-0.00052]. Положительное значение означает преимущество окна 18.
- Совместный сдвиг: перетракторная RMSE NN L2 минус NN L18 = +0.00344; условный 95% иерархический бутстреп [+0.00159;+0.00478]. Положительное значение означает преимущество окна 18.
- Повышенный шум: перетракторная RMSE NN L2 минус NN L18 = +0.00072; условный 95% иерархический бутстреп [-0.00013;+0.00186]. Положительное значение означает преимущество окна 18.

Внимание: всего три независимые обучающие выборки, поэтому интервалы **не являются доказательством универсального превосходства**. Сравнение проводится по средним траекторным RMSE, отличным от общей RMSE в таблице.

## Выводы
- Номинал: минимальная RMSE последних 40 шагов у М0 + NN, окно 2 (0.01888); М0 без NN 0.02028; NN L2 0.01888; NN L18 0.02073.
- Совместный сдвиг: минимальная RMSE последних 40 шагов у М0 + NN, окно 18 (0.02142); М0 без NN 0.02560; NN L2 0.02940; NN L18 0.02142.
- Повышенный шум: минимальная RMSE последних 40 шагов у М0 + Ridge, 18 (0.04484); М0 без NN 0.05487; NN L2 0.04879; NN L18 0.04827.
- Нелинейный сдвиг: минимальная RMSE последних 40 шагов у М0 + NN, окно 2 (0.01872); М0 без NN 0.01980; NN L2 0.01872; NN L18 0.02018.
- Полное 18-шаговое окно не является автоматически оптимальным: увеличение числа измерений даёт больше информации, но также больше шумовых входов.
- Прогнозирование остатка и улучшение поведения замкнутого регулятора остаются разными научными задачами.
- Это не доказательство устойчивости по Ляпунову, а сравнительные численные эксперименты при фиксированных ограничениях. В данном учебном контроллере шаг управления дискретен.
- Дополнительная NN не может устранить структурное ограничение недостижимого точного ненулевого равновесия при конечной сетке действий (результат 71).
