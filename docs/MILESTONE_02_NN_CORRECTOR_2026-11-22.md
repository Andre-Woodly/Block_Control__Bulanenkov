# Контрольная точка № 02 — математическая модель + нейросетевой корректор

**Дата:** 2026-11-22 · **Статус:** исследовательская постановка и учебные численные проверки зафиксированы. **Не** является валидацией регулятора реального привода.

## Зафиксированная основная архитектура

**M0 + отключаемая обучаемая поправка к прогнозу**, а не замена всей математической составляющей нейросетью:

```text
                    ┌── М0: аналитический прогноз ──┐
наблюдения, горизонт ┤                              ├─ сумма ─► прогноз
                    └── NN: оценка остатка ──────────┘
```

ŷ(t+h)=ŷ_M0(t+h)+Δŷ_NN(z_t,h). Здесь z_t — доступное измерение или наблюдаемая история. Сеть не обязана моделировать отдельную физическую силу. Остаток может объединять скрытые состояния, ошибку параметров, структурную неполноту и измерительный шум.

**Строгое разграничение:** это задача **пассивного прогнозирования**, не замкнутое управление и не доказательство стабильности/изоморфизма в смысле теории Кулабухова.

## Эксперимент 57: скрытое состояние и временная история

Пассивная учебная модель температуры воздуха и стен. Теплообмен задаётся двумя связанными линейными дифференциальными уравнениями; наблюдается только температура воздуха. Вход модели прогнозирования — либо последний отсчёт, либо история из пяти измерений, цель — четыре будущих шумных значения через 5/10/20/40 мин. **Нет входного управления, исполнительных механизмов или замкнутого контура.**

- 1000 независимых обучающих траекторий, 300 для калибровки и 1000 проверочных на сценарий;
- 5 random seed NN: 4, 17, 29, 41, 53, 1500 шагов Adam, `tanh`, два скрытых слоя по 24 нейрона;
- четыре сценария: базовый, повышенный шум, смещение распределения начальной температуры стен, изменение коэффициентов теплообмена;
- калибровка по ошибке относительно **будущих шумных измерений** с одновременным покрытием четырёх горизонтов;
- сильный аналитический эталон по истории использует **известные истинные номинальные коэффициенты**, поэтому не означает реалистичную доступность параметров в произвольной системе.

### Номинальный сценарий: RMSE по шумным будущим наблюдениям, °C

| Метод | RMSE | Покрытие 90%-го интервала |
|---|---:|---:|
| Физика по одному измерению | 0,38692 | 92,20% |
| Полная NN по одному измерению | 0,38635 | 91,10% |
| Гибрид: физика по одному измерению + NN по истории | 0,24919 | 90,56% |
| Полная NN по истории | 0,24751 | 89,00% |
| Правильная физика по истории | **0,23715** | 90,60% |

Парный бутстреп по 1000 тестовым траекториям (обученные модели фиксированы):
- NN_current − NN_history: +0,13885 °C, 95% CI **[0,12830; 0,14951] °C**.
- NN_history − Hybrid_history: −0,00168 °C, 95% CI **[−0,00444; +0,00086] °C**; преимущество гибрида не установлено.

### Сдвиг условий

| Сценарий | Гибрид RMSE | Физика по истории RMSE | Гибридное покрытие |
|---|---:|---:|---:|
| Базовый | 0,24919 | 0,23715 | 90,56% |
| Более высокий шум | 0,79733 | 0,77085 | 7,78% |
| Более тёплые стены | 0,24986 | 0,23721 | 90,46% |
| Изменённые скорости теплообмена | 0,79771 | 0,85880 | 25,44% |

При последнем сдвиге **одноотсчётный** физический прогноз (0,71700 °C) оказался точнее гибридного прогноза с историей. Не следует обобщать преимущество NN по истории на другие законы динамики.

## Статус контрольной точки

**Закрыто на синтетических данных:** архитектура M0+NN в задаче коррекции прогноза, сравнение с аналитическими базами и полной NN, эмпирическая роль истории, отдельные сдвиги распределений и калибровка по наблюдаемым данным.

**Остаётся открытым:** применение результатов к конкретному физическому объекту, оценка устойчивости замкнутого управления, соответствие критериям изоморфизма, универсальное обобщение NN на сочетания ранее неизвестных характеристик и надёжный автоматический детектор сдвига.

**Важная статистическая оговорка:** приведённые бутстреп-интервалы по тестовым траекториям не включают разброс от новых независимых *обучающих* выборок. Эталон с известной физикой не является равноправным конкурентом в условиях неизвестных параметров.
