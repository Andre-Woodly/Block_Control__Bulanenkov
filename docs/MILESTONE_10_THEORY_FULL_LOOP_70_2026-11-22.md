# Контрольная точка № 10 — теоретическая устойчивость гибридной модели с обратной связью (этап 70)

**Дата фиксации:** 22 ноября 2026 г.  
**Основная архитектура:** математическая модель М0 → оценка и пересчёт коэффициентов М0 → отключаемый NN-корректор остатка → дискретный выбор воздействия по прогнозу → обратная связь.  
**Объект проверки:** только **синтетическая пассивная тепловая система двух состояний** из экспериментов 67–69. Никаких выводов об устойчивости физического ЭГСП или авиационной системы из настоящего анализа не следует.

## 1. Непосредственно проверенный источник

Эксперимент 69 из архивного исходника `experiment69.py` и исходника 67 `experiment67_source.py`:

- Вектор физических состояний: `x = [A, W]^T`, где `A` — температура воздуха относительно базы, `W` — скрытая температура стены.
- Шаг `h=0,2`; обновление `A+ = A+h[-pa*A+pc*(W-A)-pb*A³+pg*u+d]`, `W+ = W+h*pw*(A-W)`.
- Параметры могут лежать в выпуклой оболочке пяти наборов из исходного кода 67.
- Для всех методов `|u|≤1`; по условиям теоремы `|d|≤0,06`.
- Отдельно подтверждена инвариантность прямоугольника `K={|A|≤3, |W|≤3}`; это не утверждение о качестве регулирования.
- В эксперименте 69 установлена общая квадратичная оценка для **неуправляемой** модели `V(x+ )≤ρ V(x)` при `u=d=0`, `P=diag(1,2)`, `ρ=0,9949283744800601`. Оценка действует для `x∈K`, в частности в инвариантном эллипсоиде `xᵀPx≤9`, и для указанного множества параметров.

**Важно:** NN была обучена офлайн, а во время регулирования обновлялись оценки коэффициентов математической модели. Не надо называть это онлайн-переобучением NN.

## 2. Новое следствие А: ISS-оценка физических состояний относительно воздействия

Запишем дискретную физику как `x+ = T(p,A²)x + h[pg*u+d,0]ᵀ`. При `x∈K` и указанных параметрах:

`||T(p,A²)x||_P ≤ √ρ ||x||_P`, где `||x||_P = √(xᵀPx)` и `√ρ = 0,9974609638878407`.

По неравенству треугольника, поскольку `pg≤gmax=0,8`:

**`||x+||_P ≤ 0,9974609639||x||_P + 0,2(0,8|u|+|d|)`.**

Для любого `k` внутри инвариантного множества:

`||x_k||_P ≤ (√ρ)^k||x_0||_P + 0,2(gmax*U+dmax)(1-(√ρ)^k)/(1-√ρ)`.

Здесь `U = sup_{0≤j<k}|u_j|`; `dmax` — максимальное внешнее возмущение на рассмотренном интервале. При `U=1`, `dmax=0,06` формальная асимптотическая верхняя оценка равна **67,7422** в P-норме, тогда как из доказанного инвариантного K непосредственно следует **`||x_k||_P≤√27≈5,1962`**. Следовательно, **ISS-оценка корректна, но очень консервативна и не усиливает инвариантную оценку при максимальных возмущениях**.

Это математическая оценка **физического состояния с u как ограниченным входом**, а НЕ доказательство устойчивости всего NN-контроллера, оценки параметров или ошибки слежения.

## 3. Новое следствие Б: достаточное малое усиление — условие, а не достигнутый результат

Для анализа гипотетического **замкнутого** контура без внешнего возмущения и при нулевой цели предположим, что полное отображение истории в воздействие удовлетворяет оценке

`|u_k| ≤ L0 ||x_k||_P + LH max_{1≤i≤m}||x_{k-i}||_P + ε`.

Это **дополнительное допущение**: в исходном алгоритме имеются история управляющих воздействий, оценивание коэффициентов и дискретный `argmin`; такая оценка из кода сама по себе не следует.

Обозначим `a = √ρ+h*gmax*L0`, `b = h*gmax*LH`, `D = h(gmax*ε+dmax)`. Тогда `r_{k+1} ≤ a r_k+b max(r_{k-1},…,r_{k-m})+D` для `r_k=||x_k||_P`. Если `a+b<1`, имеет место геометрическая сходимость окна истории к области размера не больше `D/(1-a-b)`; при `D=0` — локальная экспоненциальная устойчивость относительно нуля.

Из чисел № 69 следует условный численный порог:

**`L0+LH < (1-√ρ)/(h*gmax) = 0,0158689757`**.

Этот порог **не проверен** для выбранного контроллера и является лишь **сильно консервативным достаточным условием**, не необходимым требованием к устойчивости. Более того, для данного способа дискретного выбора управления глобальная гладкость отображения в `u` отсутствует.

## 4. Исследование реального алгоритма № 67: дискретные переключения и равновесие

В эксперименте 70 заново обучены 4 конфигурации NN (две независимые обучающие выборки × две инициализации, как в № 69). Сохранены исходные архитектура и параметры обучения № 67; все случайные seeds определены оригинальным скриптом 67.

Для диагностики задавалась **не физическая траектория**, а статическая тестовая история из 19 одинаковых измерений `A`, 18 прежних нулевых воздействий, при нулевой цели. Измерение A варьировалось от −0,4 до +0,4 с шагом 0,001. Проверялись четыре метода: фиксированная М0, М0 с пересчётом, М0 с пересчётом + NN и М0 с пересчётом + полином.

Для всех **16 вариантов**:

- При строго нулевой истории выбранное воздействие **u=0**.
- Разница стоимости между лучшим (нулевым) и вторым действием в точке нуля строго положительна по численному расчёту: минимум **0,002062**, максимум **0,002172** для варианта с NN. Это **вычислительное наблюдение**, не интервальная проверка точных весов.
- В сканируемом диапазоне произошло по **8 переключений** управляющего действия величиной `0,25`. Поэтому итоговое отображение истории в действие имеет разрывы на границах выбора; гладкость `tanh`-сети **не делает гладким весь регулятор**.
- Вдоль **одномерной специальной сканируемой линии истории** ближайшее изменение от нулевого действия обнаружено при `|A|≈0,028–0,029`; это не сертифицированный радиус устойчивости в пространстве всех возможных историй.

### Условный локальный вывод

Поскольку (i) стоимость каждого из девяти возможных действий непрерывна по истории при определённых весах, (ii) `u=0` имеет **строгое преимущество** в нулевой истории, то существует (возможно очень маленькая) окрестность **всего расширенного состояния истории**, где регулятор выбирает `u=0`. Для идеально бесшумной задачи с постоянной нулевой целью и согласованными малыми начальными историями в этой окрестности физическая система совпадает с неуправляемой и подчиняется `V(x+)≤ρV(x)`. После конечного сдвига истории её вспомогательные компоненты тоже стремятся к нулю.

**Итак:** при этих ограничениях имеется **условное аналитическое обоснование локальной экспоненциальной устойчивости равновесия** для *фиксированных весов* рассматриваемого дискретного алгоритма. Его численная предпосылка «положительный разрыв стоимости у нуля» проверена только в floating-point; численно удостоверенный многомерный радиус окрестности не получен.

Результат не переносится на ненулевое задание, шум, возмущения, изменение весов NN во время работы или произвольные начальные истории.

## 5. Что именно ещё не доказано

1. Глобальная или региональная **асимптотическая устойчивость полного замкнутого NN-контура** при произвольных допустимых состояниях и историях.
2. Сходимость или корректность алгоритма пересчёта коэффициентов к истинным физическим параметрам.
3. Устойчивость ошибки слежения при ненулевых и меняющихся заданиях.
4. ISS с малым и полезным остаточным радиусом относительно измерительного шума и модельной ошибки именно для **замкнутого** регулятора.
5. Выполнение оценок `L0`, `LH` для реального отображения с пересчётом, памятью и переключениями.
6. Распространение на ЭГСП: все уравнения и численные параметры в этой контрольной точке принадлежат только учебной тепловой модели.

## 6. Вывод и следующая контрольная точка

**Контрольная точка № 10 закрыта в объёме теоретического и численного аудита:** получены и проверены честные границы доказанности для полной *учебной* модели: общая инвариантная область (из № 69), ISS-оценка по входу `u,d` (№ 70), дополнительное условие малого усиления (пока не выполнено для всего регулятора) и диагностированная локальная зона с выбором `u=0`.

Следующий научный шаг — отдельная работа над **ошибкой слежения** и поиском **проверяемых условий устойчивости всего расширенного состояния** на абстрактных системах. Нельзя заменять это многократным моделированием успешных переходных процессов.
