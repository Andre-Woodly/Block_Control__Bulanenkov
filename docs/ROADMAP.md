# План учебного исследования

- [ ] Проверить библиографию и точные первоисточники, включая работу Константинова.
- [ ] Провести аудит исходных расчётов и данных статической регрессии.
- [ ] Систематизировать понятия математической модели, наблюдения, остатка и точности прогнозирования по профильной литературе.
- [ ] Исследовать прогнозирование пассивных динамических процессов на безопасных учебных данных.
- [ ] Сопоставить результаты с опубликованными исследованиями гибридной регрессии и временных рядов.
- [ ] Проверить воспроизводимость и границы применимости выводов.
- [ ] Уточнить исследовательскую гипотезу и потенциальную научную новизну.
- [ ] Подготовить редакцию статьи и список источников.

Прогресс фиксировать по завершённым и проверенным задачам, а не количеству экспериментов. Результаты прогнозирования не являются доказательством свойств замкнутого управления.
