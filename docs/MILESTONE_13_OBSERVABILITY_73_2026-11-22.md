## 2. Учебная дискретная модель

Пусть физические состояния `x_k=(A_k,W_k)` — отклонения температуры воздуха и стены; известно действие `u_k`; измерено только `y_k=A_k+η_k`. В отсутствии процесса возмущения (но только для отдельной аналитической проверки):

`A_(k+1)=A_k+h[-a A_k+c(W_k−A_k)−b A_k³+g u_k]`,  
`W_(k+1)=W_k+h w(A_k−W_k)`.

Численный шаг `h=0,2`. Номинально `a=0,13`, `c=0,09`, `w=0,045`, `b=0,055`, `g=0,8`. Для «совместного сдвига»: `a=0,20`, `c=0,145`, `w=0,028`, `b=0,23`, `g=0,61`. Это исключительно параметры синтетической тепловой системы.

## 3. Строгий результат А: наблюдаемость при известных параметрах

В идеальном случае (нет измерительного шума, нет неизвестного возмущения, известны все коэффициенты и применённое действие): из первого уравнения получаем

`W_k = {[(A_(k+1)−A_k)/h]+(a+c)A_k+b A_k³−g u_k}/c`,  при `c≠0`.

Для отображения `(A_k,W_k)→(y_k,y_(k+1))` матрица производных равна

`O = [[1, 0],[1−h(a+c+3b A_k²), h c]]`.

Её определитель `det(O)=h c`. Следовательно, если `h c≠0`, локальная наблюдаемость двух физических состояний **при известных коэффициентах** установлена; в данном примере имеет место точное алгебраическое восстановление по двум идеальным измерениям. Это **не** доказывает восстановимость параметров, если они неизвестны.

Для номинальных коэффициентов и `A_k=0` численный `cond₂(O)=106,34`. Для совместного сдвига — `64,38`. Эти значения указывают на плохую обусловленность непосредственного двухточечного восстановления в выбранных координатах.

## 4. Численный результат Б: шум при прямом восстановлении скрытого состояния

Проверен **не оптимальный наблюдатель**, а непосредственная формула предыдущего пункта. Использованы известные истинные параметры и известный `u`, отсутствие неизвестного возмущения, 160 000 независимых начальных состояний (A в [−0,35;0,35], W в [−0,45;0,45]) и действий. Отдельно сгенерирован независимый гауссовский шум на каждом из двух измерений.

| Сценарий | СКО шума измерения | RMSE восстановления W | RMSE тривиального прогноза W=0 |
|---|---:|---:|---:|
| Номинал | 0 | ≈0 | 0,2592 |
| Номинал | 0,018 | **1,3800** | 0,2592 |
| Номинал | 0,085 | **6,5258** | 0,2592 |
| Совместный сдвиг | 0,018 | **0,8437** | 0,2592 |
| Совместный сдвиг | 0,085 | **3,9730** | 0,2592 |

Это демонстрация **усиления шума при алгебраическом восстановлении по двум отсчётам**, но не отрицание возможности лучшего оценивания состояния по более длинной истории с фильтрацией. Обратимая в идеале модель не означает практически точное восстановление по шумным данным.

## 5. Строгий результат В: при отсутствии возбуждения параметры неидентифицируемы

Рассмотрим **два различных** допустимых набора физических коэффициентов. Для начального состояния `A₀=W₀=0`, постоянного `u_k=0` и `d_k=0` все выходные сигналы `A_k=0` совпадают при **любых** коэффициентах указанной модели. Следовательно, без информативных воздействий невозможно восстановить неизвестные параметры однозначно, даже из бесконечного ряда идеальных измерений. В программном тесте равенство историй для номинального и изменённого набора проверено точно.

Если вместо нуля поддерживается постоянное равновесие `A=W=r`, оно сообщает лишь комбинацию `a r+b r³=g u` и не даёт отдельной информации о `c` и `w`. Следовательно, «замкнутая обратная связь» сама по себе не гарантирует идентифицируемость.

### Что фактически оценивает 18-шаговый блок

Из исходного кода 67/72: формируется производная-разность `z_k=(y_(k+1)−y_k)/h` и регрессоры `−y_k` и `u_k`; оцениваются **два эффективных коэффициента** с регуляризацией к априорным значениям и жёсткой отсечкой интервалов. При этом истинная формула содержит дополнительный остаток:

`z_k = −(a+c) A_k +g u_k + [cW_k−bA_k³+d_k] + [η_(k+1)−η_k]/h`.

При замене `A_k` на `y_k` добавляется ещё коррелированная ошибка регрессора. Идентифицируемые аппроксимационные коэффициенты **не обязаны совпадать с физическими** `a`, `c`, `g`. Положительная определённость *регуляризованной* матрицы обеспечивает вычислительную обратимость, но не физическую идентифицируемость.

## 6. Численный результат Г: «дрейф» оценки при неизменном объекте

Чтобы изолировать методическую проблему, зафиксирован `A=W=0`, `u=0` на протяжении 18 переходов. Истинные физические характеристики не меняются; измеритель выдаёт только гауссовский шум. Запущено **160 000 независимых окон** для каждого уровня шума. Для `u=0` первый коэффициент из реально используемой 18-шаговой Ridge-регрессии сводится к

`a_hat = clip_[0,05;0,60] { [Σ(−y_k)(y_(k+1)−y_k)/h+λ a₀] / [Σ y_k²+λ] }`,

где `λ=1,5`, `a₀=0,22`. Второй коэффициент нельзя извлечь из наблюдений, так как вход всегда нулевой.

| СКО шума | Среднее значение a_hat | 5–95%-й диапазон a_hat | Доля отсечений по верхней границе |
|---|---:|---|---:|
| 0 | 0,2200 | 0,2200–0,2200 | 0% |
| 0,018 | 0,2385 | 0,2281–0,2527 | 0% |
| 0,085 | **0,5410** | 0,3917–0,6000 | **44,5%** |

Этот сдвиг не является изменением реального параметра. Он вызван корреляцией шума в регрессоре и в конечно-разностной оценке производной, а также отсечением. Ключевое тождество при независимом шуме `η_k` с дисперсией `σ²`:

`E[(-η_k)(η_(k+1)−η_k)/h] = σ²/h > 0`.

При этом `E[−η_k·u_k]=0` для фиксированного `u=0`. Даже если численная регрессия возвращает число, **данные в этом режиме вообще не содержат информации об истинных физических параметрах**.

## 7. Структура расширенного состояния и границы Ляпунова

Для анализа полного алгоритма с 18-шаговой регрессией естественно рассмотреть расширенный вектор `s_k=(A_k,W_k, y_k,…,y_(k−18), u_(k−1),…,u_(k−18))`. Он имеет 2 физических состояния, 19 сохранённых наблюдений и 18 действий, то есть 39 компонент; текущие оценки двух коэффициентов являются вычисляемыми функциями истории, а не независимыми физическими состояниями. NN использует только часть этой истории, в зависимости от длины окна.

Одна только физическая функция Ляпунова `V(A,W)` из этапов 69–71 **не удостоверяет сходимость этого расширенного состояния** или ошибку слежения при ненулевой цели. Если датчик моделируется неограниченным гауссовским шумом, у вектора истории нет детерминированной компактной инвариантной области, даже когда физические состояния остаются ограниченными. Для строгих гарантированных областей придётся предположить ограниченный шум либо перейти к вероятностным понятиям устойчивости и качества.

Это математическая постановка, а не новый доказанный результат об устойчивости полного NN-контура.

## 8. Решение для проекта и критерий завершения

**Что закрыто:** (а) наблюдаемость физического состояния при известных параметрах и отсутствии шума; (б) аналитический контрпример неидентифицируемости параметров без возбуждения; (в) воспроизводимый расчёт обусловленности; (г) проверенная по исходному 18-шаговому алгоритму демонстрация шума и смещения оценок.

**Что НЕ закрыто:** совместная наблюдаемость скрытого состояния и неизвестных параметров на информативной истории; статистически согласованная идентификация при коррелированном шуме; замкнутая устойчивость всего расширенного состояния; эффект NN при ином, несмещённом оценивателе; соответствие условиям изоморфизма в смысле первоисточника.

**Следующая предметная задача № 74:** на той же пассивной модели сравнить исходный 18-шаговый оцениватель с независимым фильтром/оценкой скрытого состояния при наличии и отсутствии информативной истории, отделив влияние оценивателя от влияния NN. И только после этого ставить общий вопрос об устойчивости полного гибридного контура с памятью.
